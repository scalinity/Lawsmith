## Design plan (two passes, reviewed against SPEC §11 and AC1–AC9)

**Pass 1.** Palette and type are the project's own tokens, not a new direction: warm-ink shell `#141311`, card `#211f1c`, text `#f3f0ea`, teal `#55aaa4` for what you edit and select, lavender `#c58ae5` for the recorded past, danger `#e0806b`; system sans for controls, the serif only for the scene title and the replay title, mono only for numbers and diagnostics. The memorable element is the viewport and its laws. Layout: one transparent grid over the full-window canvas; panels take the pointer, the gaps belong to the canvas.

```
 ●●●   [drag band: empty, invisible]                  [Undo Redo | Move Rotate Adjust | Frame Reset view]
┌ Scene card ──────────┐                                       ┌ context column (scrolls) ─┐
│ Title        Hide laws│                                      │ simulation error (if any) │
│ state · New Open Save │                                      │ recording / replay         │
│ [Open an example…]    │         VIEWPORT                     │ two futures (if any)       │
│ │ invitation          │     laws named over supports        │ Law name     Hide details │
├ Laws ─────────────────┤                                      │  selected law's inspector │
│ list, shelf, Motion   │                                      │ explained body             │
│ Display: scale        │                                      └───────────────────────────┘
└───────────────────────┘                                          [what to draw]
 diagnostics                                                       [Play Step Reset  tick]
```

**Pass 2 (review against the brief).** Rejected: a titlebar band or Build/Simulate/Explore header (AC9, SPEC §11.1); a third simultaneous column; a settings framework or persisted preference store. Kept from pass 1: a scene card that never scrolls (fixes the M2/M5 displaced file actions); the small Laws list, shelf and scene settings in the left panel, which collapses completely; one stacked context column on the right (fixes M7's banner over the comparison card) that holds the contextual panel of SPEC §11.1, the selected law's inspector beside the explained body, with its own Hide details control; a dock; and law names as the one new visible element, set in each law's own ink with a shell halo, underlined when selected and reading "off" when disabled. No new decorative motion; under Reduce motion the camera's orbit glide stops.

**Contextual panel.** The selected law's inspector is a card in the right context column, after recording and comparison and before the explained body, at the explained body's 312-unit width and within the column's existing width limits. It scrolls with that column, independently of the left panel. Hide details folds it to its title line and toggle, which stay reachable; in replay its fields are inert and the toggle is not. The inspector's selected-law refresh is the unchanged production `renderPanel`.
